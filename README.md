## 📖 产品简介

**TimiOA（天美OA）** 是一款面向企业内部的 **AI 驱动 + IM 赋能** 的智慧办公自动化系统。深度融合 **DreamingAI 企业级 AI 助手** 与 **ImSky 天信IM 跨平台即时通讯** 能力，集智能对话、流程审批、即时通讯、人事管理、资产管理、项目管理等功能于一体，为企业打造全方位的 **数智化办公新体验**。

## 🚀 使用说明

### 🌐 访问方式

1. 📱 **移动端**：通过微信小程序或手机浏览器访问
2. 💻 **桌面端**：通过 PC 客户端或浏览器访问
3. 🔐 **登录**：使用企业分配的账号密码登录系统

### ⚡ 快速开始

1. 🏠 登录系统后，在首页查看通知公告和待办事项
2. 🤖 点击 AI 助手图标，体验智能办公能力
3. 💬 进入消息中心，开始即时沟通协作
4. 🧭 通过底部导航栏切换不同功能模块
5. 📲 在"应用中心"查看所有可用功能
